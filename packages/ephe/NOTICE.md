# Data provenance — @node-jhora/ephe

This package redistributes one unmodified file from NASA's Jet Propulsion
Laboratory. Nothing in it is generated by node-jhora.

|                                                   |                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **File**                                          | `de440s.bsp`                                                                          |
| **Dataset**                                       | JPL Planetary and Lunar Ephemeris DE440, short-span kernel (1849-12-26 to 2150-01-22) |
| **Format**                                        | NAIF SPK, Type 2 Chebyshev segments                                                   |
| **Source**                                        | https://ssd.jpl.nasa.gov/ftp/eph/planets/bsp/de440s.bsp                               |
| **Mirror**                                        | https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp             |
| **Bytes**                                         | 32,726,016                                                                            |
| **SHA-256**                                       | `c1c7feeab882263fc493a9d5a5b2ddd71b54826cdf65d8d17a76126b260a49f2`                    |
| **MD5 (published by NAIF in `aa_checksums.txt`)** | `3917ee56769db332790c751e2168843d`                                                    |

Citation: R. S. Park, W. M. Folkner, J. G. Williams, D. H. Boggs,
"The JPL Planetary and Lunar Ephemerides DE440 and DE441",
_The Astronomical Journal_ 161:105 (2021), https://doi.org/10.3847/1538-3881/abd414

`prepack` runs `download.mjs`, which refuses to pack a file whose size or
SHA-256 differs from the values above. `@node-jhora/core` ships the same
pinned values and checks them again when it loads the kernel from a cache
or a download.
