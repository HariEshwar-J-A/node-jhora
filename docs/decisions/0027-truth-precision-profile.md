# ADR 0027: `'truth'` precision profile (DE440/ERFA conventions)

- Status: accepted
- Date: 2026-11-01
- Deciders: maintainers

Technical story: measured plan `truth-mode-plan.md` steps 1, 2, 3, 4, 6, and 9 (steps 5, 7, 8 deferred).

## Context

Maintainers need a third precision profile that reports apparent tropical longitudes in the **true equinox and mean ecliptic of date** frame used by ERFA/Skyfield on JPL DE440, without changing `'jhora'` or `'modern'` oracle outputs. The profile is opt-in via `precisionProfile: 'truth'`; default remains `'jhora'`.

## Decision

Implement `'truth'` as follows (all gated on `profile === 'truth'`):

| Step | Behaviour                                                                                                                                                                                                                   |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | Apparent chart longitude = mean ecliptic longitude + IAU 2000A Δψ (`nutationIau2000a`); star-defined ayanamsas add the same Δψ via `truthEquinoxOffsetDeg`.                                                                 |
| 2    | Mean ecliptic rotation = ERFA `ecm06` (IAU 2006 P03, IERS 2010 eqs. 5.39–5.41) for TT Julian days 2305448–2524594 (1600–2200), Vondrák 2011 outside with boundary join (same pattern as sidereal time in `coordinates.ts`). |
| 3    | Mean lunar node = IERS `faom03` (Simon et al. 1994).                                                                                                                                                                        |
| 4    | Apparent true node: Earth state at reception, Moon at light-time-retarded TT; Δψ from IAU 2000A.                                                                                                                            |
| 6    | Gaia DR3 astrometry for δ Cnc (`660136821288588416`) and ζ Psc (`2577061092921353984`); Spica stays van Leeuwen (2007).                                                                                                     |
| 9    | Golden tests vs `tests/fixtures/truth_profile_erfa.json` (generated by `bench/truth-profile/generate_truth_fixture.py`); bench harness fixes (pyswisseph flags, astronomy-engine TT).                                       |

Deferred to later PRs: IERS EOP/UT1 (step 5), DE441 wiring (7), daily motion (8).

## Measured residuals (engine `'truth'` vs fixture)

Fixed-ΔT cases in `truth_profile_erfa.json` (Skyfield apparent ecliptic + ERFA nodes/GAST):

| Case       | Quantity          | Residual (″) |        Plan target | Notes                                                                  |
| ---------- | ----------------- | -----------: | -----------------: | ---------------------------------------------------------------------- |
| J2000      | Sun/Moon/Pluto λ  |        ≤0.01 |             ≤0.004 | Within 0.005″ of plan slack                                            |
| 2020-01-15 | Sun/Moon/Pluto λ  |        ≤0.01 |             ≤0.004 | Same                                                                   |
| Both       | Ecliptic β (Moon) |       ~0.020 |            ≤0.0010 | Chart latitude uses IAU 2000 frame bias; Skyfield true lat — not tuned |
| Both       | True node λ       |   ~0.05–0.06 | 0.013 (same-epoch) | LT-retarded definition vs generator; within golden 0.06″               |
| Both       | Mean node λ       |        ≤0.01 |                  0 | `faom03`                                                               |
| Both       | GAST vs `gst06a`  |        ≤0.05 |  0.0002 (with UT1) | UTC-as-UT1 until step 5                                                |

No constants were fitted to library outputs.

## Consequences

- `'jhora'` and `'modern'` code paths unchanged; full golden suites must stay bit-identical.
- `@node-jhora/core` tarball grows by ~5 KB (IAU 2006 module); see pack check vs ADR 0006.
- API/schema accept `'truth'` in `PRECISION_PROFILES`.
