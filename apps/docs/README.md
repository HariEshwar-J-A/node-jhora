# Node-Jhora documentation site

Astro [Starlight](https://starlight.astro.build/) app. From the repository root:

```bash
pnpm run docs:dev
pnpm run docs:build
```

Guides are synced from `README.md`, `docs/`, and related root files at build time (`scripts/prepare-content.mjs`). Registry catalogues and the TypeDoc HTML bundle are generated by sibling scripts in `scripts/`.
